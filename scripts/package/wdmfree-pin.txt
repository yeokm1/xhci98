# (W98SE WME W2K WXP WXP64 WVISTA WVISTA64 W7 W7X64 W8 W8X64 W10 W10X64), and
# one SHA256 line per file of each package's free/<class>/<package>/ and for

# files at exactly these bytes. With no Tag line no release qualifies: the cut
# makes no download 2, and download 3 carries no WDMFREE\.
#
# The certificate (design record 26 section 6.7.11): usb-wdm-free signs its
# x64 drivers with its own test certificate, whose public half is the

# line and that file's SHA256 line go together: the cut copies the file into
# USBDRV\FREE\, hashed in its SHA256.TXT, and refuses it unless it is one DER
# certificate with no private key and this thumbprint. The Certificate line
# may stand alone before a release qualifies; it is the owner's certificate
