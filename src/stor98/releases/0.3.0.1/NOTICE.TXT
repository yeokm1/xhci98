## Microsoft DDK headers

Not included. The Windows 9x build needs `SCSI.H` and `SRB.H` from the Windows 98 or NT4
DDK; place them in `tools/w98ddk/inc/` (git-ignored). The other kits (MSVC 6.0, Windows 2000
DDK, WDK 7.1) live in `tools/` too; see `docs/BUILD.md`.

## CM interface header

`include/stor98cm.h` is original to this project (Yeo Kheng Meng, BSD-3-Clause). It defines
the interface between xhci98's connection manager and stor98 and is licensed on its own as
an interface definition, so that xhci98 (GPL-2.0) can include it unchanged; the file says
so in its header.
